GitHub badges tutorial and achievement sandbox

Practice GitHub achievements with real pull request workflows.

Git Badges Playground helps developers learn GitHub profile badges by running guided local scripts for Pull Shark, YOLO, Quickdraw, and Pair Extraordinaire in their own repository.

Open GitHub Repo Read Badge Guide

What it covers

Pull SharkMerged pull request practice with automated branches and PRs.
YOLOMerge-without-review practice in a repo you control.
QuickdrawCreate and close an issue quickly through GitHub CLI.
Pair ExtraordinaireCreate a co-authored commit and merge it through a PR.

Fast start

git clone https://github.com/YOUR_USERNAME/git-badges.git
cd git-badges
npm start

That is the TypeScript playground. It needs Node.js 22.18+, GitHub CLI, and an authenticated account. To skip the menu, run npm start -- pull-yolo.

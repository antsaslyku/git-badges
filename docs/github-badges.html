Fast start

2 commands

Fork the repo, clone your fork, authenticate GitHub CLI, and run the script. The playground writes small entries to playground-log.md so each pull request has a real change.

git clone https://github.com/YOUR_USERNAME/git-badges.git
cd git-badges
gh auth login
npm start
npm start -- pull-yolo
npm start -- quickdraw
npm start -- pair --coauthor-name "Name" --coauthor-email "email@example.com"

Pull Shark

Merged PRs

Pull Shark is tied to merged pull requests. The playground creates two branches, opens two pull requests, merges them, and deletes the remote branches.

  1. Run pull-yolo mode in a public repo you control.
  2. The script creates a branch and commits a small log entry.
  3. GitHub CLI opens and merges the pull request.
  4. The process repeats for a second merged pull request.
npm start -- pull-yolo

YOLO

No review

YOLO is tied to merging a pull request without a code review. The same pull-yolo flow merges directly, which is why it can practice both YOLO and Pull Shark.

If your repo has branch protection requiring reviews, this flow cannot trigger YOLO. Use a sandbox repo you own with no required review rule.

Quickdraw

Under 5 min

Quickdraw is tied to opening and closing an issue or pull request quickly. The playground creates an issue and closes it immediately through GitHub CLI.

npm start -- quickdraw

Pair Extraordinaire

Co-author

Pair Extraordinaire is tied to a merged pull request containing a valid co-authored commit trailer.

Co-authored-by: Name <email@example.com>

Use a real GitHub email for the co-author. Fake or unmatched emails may not count.

npm start -- pair --coauthor-name "Name" --coauthor-email "email@example.com"

Harder badges

Real activity
Starstruck Build a repo people genuinely want to star. Add screenshots, clear docs, useful topics, and share it with the right audience.
Galaxy Brain Answer real questions in public repository Discussions. Accepted answers are controlled by the author or maintainers.
Public Sponsor Sponsor a maintainer or project through GitHub Sponsors. This one involves payment.

Responsible use

Keep it clean

This playground is for your own repos and forks. Do not spam maintainers, open fake pull requests in other projects, buy stars, or flood Discussions with low-quality answers.

Badges are fun. Real GitHub activity is better.
